# 🐾 PawLux – Pet Shop Premium

Landing page de um pet shop de alto padrão, desenvolvida como atividade prática de Engenharia de Prompt.

---

## 📁 Estrutura de Pastas

```
OUTRAIA/
├── html/
│   └── index.html
├── css/
│   └── style.css
└── javascript/
    └── script.js
```

---

## 🚀 Como Rodar

1. Abra a pasta `OUTRAIA` no **VS Code**
2. Clique com o botão direito no arquivo `html/index.html`
3. Selecione **"Open with Live Server"**
4. O site abre automaticamente no navegador

> ⚠️ Sempre abra pelo `index.html` dentro da pasta `html/`. Se abrir de outro lugar os arquivos CSS e JS não carregam.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica da página
- **CSS3 puro** — estilização, animações e responsividade (sem frameworks)
- **JavaScript Vanilla** — lógica do formulário (sem bibliotecas)
- **Google Fonts** — fontes Syne e Inter

---

## ✨ Funcionalidades

- Dark mode moderno com efeito neon violeta
- Navbar fixa com botão de agendamento
- Seção de serviços com tempo estimado e selo "Mais Vendido"
- Animação de fade-up nos cards ao rolar a página
- Formulário de agendamento com:
  - Máscara automática no campo de telefone `(00) 00000-0000`
  - Bloqueio de datas anteriores ao dia de hoje
  - Validação completa de todos os campos
  - Mensagem de sucesso ao confirmar

---

## 📄 Atividade

Projeto desenvolvido para o **Desafio de Engenharia de Prompt & Teste Comparativo de IA**, utilizando técnica de prompt estruturado com os blocos:

- `[PAPEL]` — define o perfil do desenvolvedor para a IA
- `[CONTEXTO]` — regras de UX e negócio
- `[STACK TÉCNICA]` — linguagens e restrições de uso
- `[RESTRIÇÕES DE CSS]` — paleta, tipografia e animações
- `[RESTRIÇÕES DE JS]` — validações e máscaras
- `[RESULTADO ESPERADO]` — formato de entrega
